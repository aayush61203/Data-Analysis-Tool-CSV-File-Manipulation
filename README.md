#  Data Analysis Tool CSV File Manipulation🧰

A simple Python tool for analyzing and manipulating **CSV files**.  
Perfect for basic data exploration and analysis.  

### Features ✨
- **Display DataFrame**: View the entire dataset
- **Descriptive Statistics**: Get summary statistics for the data
- **Sum and Count Operations**: Perform sum/count on selected columns
- **Missing Value Handling**: Fill or drop missing values easily
- **Data Visualization**: Generate plots like histograms, scatter plots, and heatmaps
- **Data Filtering & Sorting**: Filter rows based on conditions, sort by columns
- **Column & Row Operations**: Max, Min, specific row selection, and more!

## 🎮 How to Use for Normal Users

1. **Clone the Repository**  
   Use the following command to clone the repo:
   ```bash
   git clone https://github.com/aayush61203//Data-Analysis-Tool-CSV-File-Manipulation.git
   ```
   
2. **Install Dependencies**  
   Make sure you have **Python 3.x** installed. You can install the required dependencies using:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Program**  
   To launch the application, simply run:
   ```bash
   python main.py
   ```

4. **Choose the Option**  
   Once the program starts, you'll be presented with a **menu**. Choose the corresponding number to execute a specific action:
   - Display data (`1`)
   - Calculate sum of a column (`9`)
   - Plot a histogram (`35`)
   - And many more!

5. **Exit**  
   To exit the application, choose option **`0`**.
